# PC 모니터 (PCMonitor)

Windows PC·서버가 **왜 멈추는지**, **누가 침입하려 하는지**, **무엇을 정리하면 되는지**를 한 화면에서 보여 주는 가벼운 모니터링 프로그램입니다.
설치하면 백그라운드에서 조용히 기록하고, 문제가 생기면 알림을 띄웁니다. 화면은 이 PC 안에서만 열리며 인터넷으로 아무것도 보내지 않습니다.

- CPU 1% 미만 · 메모리 50MB 안팎 · 저장 공간 5~20MB에서 더 늘지 않음 (오래된 기록 자동 삭제)
- Windows 10/11, Windows Server 2016 이상 (최소 8.1 / 2012 R2)

---

## 주요 기능

| 탭 | 하는 일 |
|---|---|
| **개요** | CPU·메모리·커밋·디스크·네트워크 그래프(그래프를 누르면 그 시점의 상위 프로세스), 프로세스 설명·권장(필수/종료 가능/삭제 가능), **Windows 업데이트·백신 검사 진행 상황**, 위험 항목 바로 보기 |
| **침입 감시** | 3초마다 갱신: 들어온 외부 연결, 방화벽이 막은 접속 시도(포트 스캔 탐지), 로그인 실패·원격 로그인, 원격 세션, 열린 포트, 인터넷과 통신 중인 프로그램 |
| **흔적 점검** | 백도어 계정, 원격 제어 프로그램(TeamViewer 등), 백신 예외, 숨은 자동실행(WMI·IFEO·Winlogon), 서명 없는 프로그램, 로그 삭제·원격 로그인 이력 — 항목마다 **제거·격리·삭제·끄기 버튼**, 괜찮은 항목은 **무시**(기록이 남고 언제든 다시 표시) |
| **프로그램** | **인터넷뱅킹 보안 프로그램 관리**(외부 접속 차단, 뱅킹 사이트를 열 때만 자동으로 켜기), 이름 일부로 **바로 찾기**(실행 중·설치됨·디스크의 실행 파일, 서명·회사 표시, 종료·제거·삭제 버튼), **내 메모**(프로그램별 설명·판단 기록 → 프로세스 목록에 표시) |
| **장애 기록** | 비정상 종료(블루스크린·강제 종료) 후 재부팅되면 **멈추기 직전 5분**의 자원 사용과 프로세스를 자동 저장 |
| **보안 / 전체 이벤트** | Defender·방화벽 상태, 보안 이벤트 목록 |
| **정보** | PC 모니터 자신의 자원 사용량·외부 통신 여부, 작동 원리, 안전성 설명 |

## 설치

### 실행 파일(권장, 파이썬 필요 없음)

1. [Releases](../../releases)에서 `PCMonitor.zip`을 받아 압축을 풉니다. (`PCMonitor.exe`와 `_internal` 폴더가 항상 같은 폴더에 있어야 합니다)
2. **`Install.cmd`를 더블클릭**하고 관리자 권한 확인 창에서 **[예]** 를 누릅니다.
3. 바탕화면·시작 메뉴의 **PC 모니터**로 엽니다.

| | PC | 서버 |
|---|---|---|
| 설치 위치 | `C:\Program Files\PCMonitor` | 같음 |
| 기록 위치 | `C:\ProgramData\PCMonitor` | 같음 |
| 시작 방식 | 설치한 사용자가 로그인하면 시작 | PC가 켜지면 로그인 없이 SYSTEM으로 시작 |
| 알림 | Windows 알림 센터 | 로그인한 사용자 화면에 메시지 창 |

바꾸려면: `install.ps1 -Mode User` 또는 `install.ps1 -Mode System`

### 파이썬으로 실행

```powershell
pip install psutil
python monitor.py --background      # 모니터 본체
python monitor.py                   # 화면(앱 창) 열기
# 자동 실행 등록: 관리자 PowerShell 에서
powershell -ExecutionPolicy Bypass -File install.ps1
```

### 끄기 · 알림 줄이기

앱 창을 닫아도 모니터는 뒤에서 계속 돌며 알림을 띄웁니다. 오른쪽 위 **[알림]** 버튼에서:

- **알림 팝업**: 모두 보기 / 위험만 보기 / 끄기, 또는 1시간·8시간·하루 동안 잠시 끄기 (팝업만 줄이고 감시·기록은 계속, 경고는 '전체 이벤트'에 남음)
- **모니터 끄기**: 감시·기록·알림을 모두 멈춤. 다음 로그인(서버는 부팅) 때나 PC 모니터 아이콘을 열면 다시 켜집니다. 계속 꺼 두려면 관리자 PowerShell에서 `Disable-ScheduledTask -TaskName PCMonitor`.

알림은 알림 센터에 **PC 모니터** 이름으로 표시됩니다 (현재 사용자 레지스트리 `HKCU\Software\Classes\AppUserModelId\PCMonitor.App` 에 등록, 제거할 때 함께 삭제).

### 제거

`Uninstall.cmd` 더블클릭. 기록까지 지우려면 관리자 PowerShell에서 `uninstall.ps1 -DeleteData`.

## 작동 원리

```
                ┌──────────────── PCMonitor (백그라운드, 관리자 권한) ────────────────┐
 Windows 성능 ──▶│ 수집기 (10초)  CPU·메모리·디스크·네트워크·상위 프로세스 + 생존 신호   │──▶ SQLite
 이벤트 로그 ───▶│ 보안 감시 (1분) 로그인·백신·서비스 설치·로그 삭제·PowerShell 공격 패턴 │      (data/pcmon.db)
 방화벽 기록 ───▶│ 침입 감시 (5초) 차단된 접속 시도 집계 → 포트 스캔·외부 접속 탐지       │
 자동실행 목록 ─▶│ 변화 감시 (10분) 시작프로그램·서비스·예약 작업·열린 포트 기준선 비교   │
 시스템 설정 ───▶│ 흔적 점검 (하루) 계정·원격 접속·백신 예외·숨은 자동실행·서명 검사      │
                │ 업데이트/검사 (30분/30초) Windows 업데이트 목록, 백신 검사 진행률 추정 │
                │ 웹 서버 127.0.0.1:8765  ── 화면(앱 창) ── 조치 버튼(확인 후 실행)       │
                └───────────────────────────────────────────────────────────────────┘
```

### 멈춤·강제 종료 원인 추적
수집기는 10초마다 기록과 함께 **생존 신호(heartbeat)** 를 남깁니다. 재부팅 뒤 마지막 생존 신호가 부팅 시각보다 앞서 있고 그 사이에 `Kernel-Power 41`·`EventLog 6008`이 있으면 비정상 종료로 판단해,
블루스크린 코드(BugcheckCode)·전원 버튼 여부와 함께 **직전 5분의 기록**을 장애 보고서로 저장합니다.

### 침입 시도 탐지
- **방화벽 차단 기록**(`pfirewall.log`)에서 수신 DROP 중 실제 접속 시도(TCP SYN, ICMP 에코, 응답이 아닌 UDP)만 골라 1분 단위로 집계합니다.
  한 출처가 1분에 10개 이상 포트를 두드리면 **포트 스캔**, 인터넷 IP의 시도는 **외부 접속 시도**로 경고합니다.
- **보안 로그**: 로그인 실패(4625), 원격 로그인 성공(4624 유형 3·10), 계정 생성(4720), 관리자 그룹 추가(4732), 로그 삭제(1102·104).
- **PowerShell**: Windows가 의심 표시한 스크립트(4104 경고) 중 원격 다운로드 실행·백신 무력화·메모리 주입 같은 실제 공격 패턴만 경고합니다.

### 흔적 점검
읽기 전용 PowerShell 한 번으로 계정·원격 접속 설정·공유·백신 예외/탐지 이력·hosts/프록시·WMI 구독·IFEO·Winlogon·예약 작업·방화벽 허용 규칙을 모으고,
사용자 폴더(다운로드·AppData·Temp 등)에 있는 실행파일은 **디지털 서명**을 확인해 서명 없는 프로그램을 찾습니다.

### 조치(제거·격리·삭제)
| 대상 | 방법 |
|---|---|
| 설치된 프로그램 | Windows "앱 제거" 목록의 공식 제거 프로그램 실행 (가능하면 조용히). 이름·제품명·설치 폴더 이름으로 찾되 **정확히 하나로 특정될 때만** 버튼 표시 |
| 실행파일 | 프로세스 종료 → 관련 방화벽 허용 규칙·자동실행 삭제 → **격리**(되돌리기 가능) 또는 **휴지통으로 삭제** |
| 위험 설정 | 원격 지원·원격 데스크톱·SMBv1·Guest 끄기, 백신 예외 삭제, KMS 설정 삭제, 의심 예약 작업 끄기, IP 차단 등 |

### 무시 · 메모
- **무시**: 흔적 점검 항목(예: 원격 지원 허용)은 다시 점검해도 계속 숨기고, 경고 이벤트는 "이번만 확인함" 또는 "같은 경고 계속 무시"를 고를 수 있습니다. 숫자만 다른 같은 항목(예: 로그인 실패 3회/5회)은 같은 것으로 봅니다. 모든 무시는 시각과 함께 기록되고 **[다시 표시]** 로 되살립니다.
- **메모**: 프로그램 이름별로 메모와 판단(안전·확인 필요·삭제 예정)을 남기면, 그 프로그램이 나오는 곳마다 설명 대신 메모가 보이고 권장 등급도 메모를 따릅니다.

### 인터넷뱅킹 보안 프로그램
nProtect·CrossEX·TouchEn·Wizvera·IPinside·공동인증서 도구 같은 프로그램은 PC가 켜지면 항상 실행되고, 일부는 다른 기기에서도 접속할 수 있는 포트를 엽니다.
사이트(URL) 단위로 제한하는 설정은 이 프로그램들에 없어서 같은 효과를 내는 두 가지를 제공합니다.
- **외부 접속 차단**: 방화벽 "들어오는 연결 차단" 규칙을 프로그램별로 추가. Windows 방화벽은 같은 PC 안의 연결(127.0.0.1)은 막지 않으므로 브라우저 뱅킹은 그대로 됩니다.
- **실행 방식**: 항상 켜 둠(원래대로) / **뱅킹 사이트를 열 때만 자동으로 켜기**(창 제목에 은행·홈택스 등 키워드가 보이면 켜고, 닫힌 뒤 N분 지나면 끔. 키워드는 편집 가능) / 꺼 둠. 끌 때 서비스 시작 방식·로그인 시 자동 실행을 보관해 두었다가 **원래대로 되돌리기**로 복구합니다.

### 화면 언어
오른쪽 위 **[EN] / [한국어]** 버튼으로 바꿉니다. 번역은 `i18n_en.json` 한 파일에 있어 화면·확인 창·알림 팝업이 같이 바뀝니다. 사전에 없는 문구는 한국어로 남으니, 번역 개선은 이 파일을 고치거나 Issues로 알려 주세요.

### 트레이 아이콘 및 종료 옵션
- **트레이 아이콘**: 백그라운드 감시가 실행 중일 때 작업 표시줄 오른쪽 알림 영역에 PC 모니터 아이콘이 상주합니다.
  - 더블클릭 / 좌클릭: PC 모니터 화면 열기
  - 우클릭 메뉴: 화면 열기 / **백그라운드 감시 종료** (확인 창 후 수집·감시 프로세스 완전 종료)
- **UI 종료 옵션**: 화면 오른쪽 위 **[종료]** 버튼 또는 [정보] 탭에서 제어합니다.
  - **트레이로 최소화 (권장)**: 화면 창만 닫고 트레이에서 장애 원인 추적·침입 감시·뱅킹 보안 보호를 계속 유지합니다.
  - **백그라운드 완전 종료**: 화면뿐 아니라 백그라운드 수집기, 감시 장치, 웹 서버 프로세스를 모두 종료합니다.
  - 창 닫기(X) 시 기본 동작(트레이로 최소화 또는 백그라운드까지 항상 종료)을 [정보] 탭에서 설정할 수 있습니다.

### 백신 검사 진행률
Windows는 검사 진행률을 제공하지 않습니다. 전체 검사는 **백신 엔진(MsMpEng)이 읽은 데이터 양 ÷ 디스크 사용량**으로, 빠른 검사는 **지난번 검사 시간 대비 경과 시간**으로 추정합니다.

## 안전성

- **외부 통신 없음** — 서버 접속·자동 업데이트·사용 통계 전송이 없습니다. 정보 탭에서 실제 연결 수를 확인할 수 있습니다.
- **로컬 전용 화면** — `127.0.0.1`에만 열리고 Host 헤더를 검사해 DNS 리바인딩을 막습니다.
- **접근 열쇠** — 기록 폴더(설치 사용자·관리자·SYSTEM만 접근 가능)에 저장된 무작위 열쇠가 있어야 화면을 볼 수 있습니다. 서버의 다른 원격 사용자는 볼 수 없습니다.
- **임의 명령 불가** — 조치 요청은 사용자 정의 헤더 + 열쇠 쿠키가 있어야 하고, 화면은 서버가 만든 **조치 번호만** 보낼 수 있습니다. 실제 경로·명령은 서버에만 있습니다.
- **보호 장치** — Windows 폴더·Microsoft 서명 파일·PC 모니터 자신은 삭제/격리하지 않으며, 모든 조치는 확인 창을 거치고 이벤트 기록에 남습니다.
- **되돌리기** — 격리는 원래 위치·방화벽 규칙·자동실행까지 복구, 삭제는 휴지통으로 이동.

### 설치 시 바뀌는 Windows 설정
- 로그인 성공/실패 감사 켜기 (`auditpol`)
- Windows 방화벽 차단 기록 켜기 (최대 4MB)
- 자동 실행 작업 `PCMonitor` 등록
- Defender 바이러스 정의 업데이트 요청

## 구성

| 파일 | 역할 |
|---|---|
| `monitor.py` | 본체·런처. 관리자 권한/`--background`이면 모니터, 아니면 앱 창 열기 |
| `db.py` | SQLite 저장, 5분 요약, 보관 기간 정리 |
| `security.py` | 이벤트 로그 감시, 자동실행 변화, 열린 포트, 서명 없는 실행파일, Defender·방화벽 상태 |
| `intrusion.py` | 방화벽 차단 기록 분석, 실시간 침입 현황, 흔적 점검 |
| `remediate.py` | 제거·격리·삭제·설정 조치, 프로세스 종료, 위험 이벤트 설명 |

## 직접 빌드

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1    # → dist\PCMonitor.zip
```

exe 한 개(`--onefile`)가 아닌 폴더(`--onedir`, `PCMonitor.exe` + `_internal`)로 만듭니다.
`--onefile`은 실행할 때 자기 안의 파일을 임시 폴더에 풀어 실행하는데, 이 방식이 악성코드와 비슷해 백신(V3 등)이 오진하는 일이 많기 때문입니다.
아이콘을 새로 만들려면 `pip install pillow` 후 `python make_icon.py pcmon.ico`.

## 문제 해결

| 증상 | 확인 |
|---|---|
| 화면이 안 열림 | `C:\ProgramData\PCMonitor\pcmon.log` 확인. 포트 8765가 쓰이고 있으면 환경변수 `PCMON_PORT`로 변경 |
| "접근 권한이 없습니다" | 설치한 계정에서 바로가기 아이콘으로 열어야 합니다 |
| 로그인 기록이 안 보임 | 관리자 권한으로 실행 중인지(정보 탭), 도메인 GPO가 감사 정책을 덮어쓰는지 확인 |
| 백신 진행률이 안 나옴 | 검사 시작 후 10분 정도 지켜본 뒤 표시. "PC를 안 쓸 때만 검사" 설정이면 사용 중에는 거의 멈춤 |
