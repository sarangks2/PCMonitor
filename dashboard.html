보안 이벤트 (30일)

프로그램 바로 찾기

실행 중인 프로세스, 설치된 프로그램, 디스크의 실행 파일(PATH·Program Files·AppData·다운로드)을 찾습니다. 인터넷으로는 아무것도 보내지 않습니다.

내 메모 프로그램에 남긴 메모는 프로세스 목록 등에서 설명 대신 표시됩니다

PC 모니터가 지금 쓰는 자원 10초마다 갱신

작동 원리

  1. 수집 — 10초마다 CPU·메모리·디스크·네트워크 사용량과 상위 프로세스를 기록합니다. Windows가 이미 제공하는 정보(성능 카운터)를 읽기만 합니다.
  2. 멈춤 추적 — 기록할 때마다 "살아 있음" 표시를 남깁니다. 재부팅 뒤 이 표시가 끊긴 시각과 Windows 종료 기록(Kernel-Power 41 등)을 맞춰 보고, 멈추기 직전 5분을 장애 기록으로 남깁니다.
  3. 보안 감시 — Windows 이벤트 로그(로그인, 백신, 서비스 설치)와 방화벽 차단 기록을 읽고, 자동실행 목록·열린 포트의 변화를 비교합니다.
  4. 흔적 점검 — 하루 한 번 계정·원격 접속·백신 예외·숨은 자동실행·서명 없는 프로그램을 확인합니다.
  5. 조치 — 사용자가 버튼을 누르고 확인했을 때만 제거·격리·차단을 실행합니다. 자동으로 무언가를 지우지 않습니다.
  6. 정리 — 오래된 기록은 스스로 지워서 저장 공간이 일정 크기 이상 늘지 않습니다.

안전한 이유

  • 인터넷으로 아무것도 보내지 않습니다. 외부 서버 접속·자동 업데이트·사용 통계 전송이 없습니다. 아래 "외부 통신"이 실제 연결 수를 보여 줍니다.
  • 이 PC 안에서만 열립니다. 화면은 127.0.0.1(자기 자신) 주소로만 열려 다른 기기에서 접속할 수 없습니다.
  • 설치한 계정만 볼 수 있습니다. 접근 열쇠가 있어야 화면을 볼 수 있고, 다른 사이트가 몰래 조치 버튼을 누를 수 없게 막았습니다.
  • 임의 명령을 실행하지 않습니다. 화면은 점검에서 만든 조치 번호만 보낼 수 있고, Windows 시스템 파일·Microsoft 서명 파일은 지우지 않습니다.
  • 되돌릴 수 있습니다. 격리는 되돌리기가, 삭제는 휴지통 복원이 가능합니다.
  • 소스가 공개돼 있습니다. 모든 동작을 코드로 확인할 수 있습니다.

Windows 설정에 하는 일

  • 로그인 성공/실패 감사 켜기 (침입 시도 기록용)
  • Windows 방화벽 "차단 기록" 켜기 (최대 4MB, 접속 시도 감시용)
  • 자동 실행 작업 'PCMonitor' 등록
  • 그 밖의 설정은 버튼을 눌러 확인한 경우에만 바꿉니다
